# 挨饿荒野 · 物资地图

游戏《挨饿荒野》各地图物资摆放位置的可视化网页：缩放/拖拽查看地图，按物资筛选并显示摆放圆点，支持搜索、最多 5 种物资同时叠加显示。

顶栏一个**模式下拉框**，四种视图互斥切换：

| 模式 | 内容 |
|---|---|
| **物资位置** | 各图物资摆放点（圆点），支持搜索、自定义颜色/大小、最多 5 种叠加 |
| **猎物区域** | 各图**猎物活动区矩形框**（哪些坐标范围内能刷出/抓到该猎物），可多选高亮 |
| **种植坑** | 叠一层**小圆点**（5px，三种坑型三色）标出存档里每个种植坑的位置；坑里种了什么属于玩家自己的存档数据，**不展示** |
| **危险动物** | 可进猎杀陷阱的 12 种动物的**巢穴**（菱形），并以巢穴为圆心画出该物种 AI 的**追击半径圈**（椭圆，按地图非等比缩放） |

## 页面功能

**地图操作**：滚轮/双指缩放、拖动平移，顶栏切换 15 张地图；缩放时圆点大小自适应（放大不糊、缩小不断）。

**物资位置 Tab**

- 左侧列表按摆放数量排序，点击叠加到地图（最多 5 种），搜索框按名称/英文名/编号过滤；
- 顶栏「按物品聚合」：把同一物品的地面/树上/雪地/水面等多个模型合并成一条，点一次高亮全部变体点位；
- 左下角图例每行可改圆点颜色与大小，`↺ 恢复默认样式`，设置按浏览器本地保存。

**猎物区域 Tab**：按猎物多选高亮其活动区矩形框，悬停显示坐标范围。

**种植坑模式（顶栏下拉框）**：三种坑用三种颜色区分——地面小坑（`Prefab/Plants/LandNitu`，青蓝）、地面大坑（`BigLandNitu`，黄）、水里的种植坑（`WaterNitu`，绿）。数据来自存档数据库 `marooned_plants_data` 表，共 **1614 个坑 / 15 张地图**（图11 最多 204 个）。坑点用小圆点（5px）与物资的 4px 圆点靠颜色区和大小区分。

**危险动物模式（顶栏下拉框）**：把**能进猎杀陷阱的 12 种动物**的巢穴画成 5px 菱形（与物资圆点同尺寸，靠颜色区分物种）。**默认不画追击圈**，点左侧某个物种后才画出该物种的圈并加深（2px 边框 + 发光），再点一下取消。半径取自 `libil2cpp.so` 里各 AI 的 `ThinkWhatToDo` / `FixedUpdate` ——「距离超过 N 就放弃追击」的浮点常量（判定形式统一为 `vsqrt.f32` + `vcmp.f32`）：

| AI 类 | 半径（世界单位） | 小地图显示 | 对应物种 |
|---|---|---|---|
| `WolfAI` | 60 | 120 m | 狼 |
| `LiegouAI` | 60 | 120 m | 鬣狗 |
| `LionAI` | 50 | 100 m | 美洲狮、美洲豹 |
| `EmoAI` | 40 | 80 m | 暗影恶魔 |
| `BearAI` | 35 | 70 m | 棕熊、犀牛 |
| `HemaAI` | 35 | 70 m | 河马 |
| `DaeyuAI` | 20 | 40 m | 鳄鱼（回巢放弃距离） |
| `JuxiAI` | 20 | 40 m | 巨蜥（回巢放弃距离） |
| `MiguanAI` | 25 | 50 m | 蜜獾、土狼（回巢放弃距离） |

**关于单位（重要）**：几何上 **1 世界单位就是 1 米**——主角胶囊体 1.80 高 / 0.21 半径、狼 1.30 / 0.28、兔子 0.50 / 0.16，都是从 prefab 的 Collider 读出来的；AI 里的距离判定是 `vsqrt.f32` 后直接 `vcmp.f32` 常量，中间没有任何乘除系数。
但**游戏小地图上显示的“米”是它的 2 倍**：图8 挪威雪山三个营地在存档里是 A(142.53,-89.89)、B(-112.39,20.6)、C(73.45,0.12)，从 B 出发的直线距离分别是 **187.0 / 277.8**，游戏里点位提示分别显示 **374 / 556**，比值 2.000 / 2.001（两段独立路径都精确翻倍）。把存档坐标按 1:1 和 ×2 分别画到游戏底图上也能看出来：1:1 三个营地全在岛上，×2 全掉进海里 —— 所以存档/地图坐标本身是 1:1 的，翻倍只发生在距离显示上。
因此网页里**圈的大小按世界单位画**（与底图比例一致，几何正确），**数字标签按小地图口径显示**（`dHud()` 里 ×2），避免和游戏里看到的数对不上。

因为底图是**非等比**贴合世界矩形的（x/z 比例不同），半径圈实际渲染成椭圆。这 12 种巢穴的点位已从**「物资位置」里隐藏**（它们的物件 id 记在 `危险动物.json` 的 `meta.nestIds`），只在危险动物模式出现，避免同一批点位在两处重复计数；交互与「猎物区域」一致 —— 默认不选，点物种条目高亮该物种、其余淡化，可多选，「清空」取消选择。数据 `data/危险动物.json` 由 `pythonTool/导出危险动物.py` 从 `物资位置.json` + `物件变体.csv` 归类生成。

**动物一览**：`data/动物一览.csv` 把官方名称表里的动物相关条目分成活体 / 尸体 / 生肉食材 / 熟食 / 皮材料五类，并标注**能否进猎杀陷阱**（= 该动物的 AI 重写了 `AnimalEnterTheDangerTrap`）。可捕的共 **12 种**：狼 Wolf、鬣狗 Liegou、鳄鱼 Daeyu(Eyu)、棕熊 Bear(Beer)、巨蜥 Juxi、蜜獾 Miguan、河马 Hema、暗影恶魔 Emo、美洲狮 Lion，以及**复用父类 AI 的三种**——犀牛 Xiniu（挂 `BearAI`）、土狼 Tulang（挂 `MiguanAI`）、美洲豹 Bao（挂 `LionAI`）。后三条是对 `data.unity3d` 里 prefab 的 MonoBehaviour 脚本逐一读取 `m_Script → MonoScript.m_ClassName` 证实的，不是按名字猜的。

**其它**：物资没有图标时显示名称首字徽标（彩色方块）；「背景图」开关控制羊皮纸底衬。

## 文件结构

```
物资一览/
├── index.html            # 入口页（与 物资地图.html 内容一致）
├── 物资地图.html          # 主页面（地图渲染 + 两个 Tab 的全部逻辑）
├── data/                 # 页面运行时 fetch 的数据（仓库只发布这 7 个）
│   ├── 物资位置.json       # 各图物资摆放点（15 图 / 19254 点）
│   ├── 物资映射.csv        # 编号 → 名称 / 英文名 / 预制体 / 图标（252 条）
│   ├── 物件变体.csv        # 物件 → 预制体 / 变体 / 所属物品（620 条）
│   ├── 地图矩形.json       # 各图官方坐标矩形（Constants.sceneDituWHMap）
│   ├── 种植坑.json         # 存档里玩家挖的种植坑（1614 个，三种坑型）
│   ├── 动物一览.csv        # 动物相关条目分类 + 能否进猎杀陷阱（170 条）
│   └── 危险动物.json       # 12 种可捕动物的巢穴坐标 + AI 追击半径
├── 地图图片/              # 15 张地图底图 + 羊皮纸底衬 dituBack.png
└── wupingIcon/            # 物资图标（页面优先从这里加载，缺失则回退 assets）
```

## 说明

> ⚠️ **`物资映射.csv` 的「编号」是「物件 id」（地图上摆放的那个东西），不是 Wuping 物品 id。**
> 两者数值空间不同，早期有 26 行曾按同号 Wuping 枚举填英文名、6 行动物巢按同号物品填中文名，
> 导致图10 的科莫多巨蜥巢被写成「大雪块 / GoodSnow」。现已用 `pythonTool/修正物件误命名.py`
> 修正：英文名一律取物件预制体名、动物巢中文名取官方表的动物名、图标取官方表的图标路径。
> 后续新增条目请以 `data/物件变体.csv` 的「预制体」为准，不要按编号去查 Wuping。

页面为纯静态资源，无后端、不收集任何数据；游戏素材版权归原作者，本项目仅供学习交流。

`data/` 下只有上面 7 个文件是页面实际加载的；存档数据库、名称全量表、猎物区域源数据、
预制体中间表等属于本地导出产物，不随仓库发布（`.gitignore` 已排除）。

## 维护脚本（`pythonTool/`，本地保留不入库）

| 脚本 | 作用 |
|---|---|
| `导出物资位置.py` | 存档数据库 → `data/物资位置.json` |
| `导出种植坑.py` | 存档 `marooned_plants_data` → `data/种植坑.json` |
| `导出动物一览.py` | `物资名称.csv` → `data/动物一览.csv`（分类 + 猎杀陷阱可捕） |
| `导出危险动物.py` | `物资位置.json` + `物件变体.csv` → `data/危险动物.json`（巢穴 + 追击半径） |
| `补齐图标.py` | 按官方图标路径从 `data.unity3d` 取图标并回填 CSV |
| `修正物件误命名.py` | 按物件预制体修正被误填成 Wuping 枚举的名称/图标 |
| `新增HTML_模式下拉框.py` | 四合一模式下拉框 + 种植坑图层（幂等） |
| `新增HTML_危险动物专区.py` | 注入「危险动物」模式：巢穴 + 追击半径圈（幂等） |
| `新增HTML_猎物区域页.py` / `新增HTML_物资数据外置.py` / `新增HTML_模式下拉框.py` | 注入猎物 Tab / 外部数据源 / 四合一模式下拉框（幂等） |

改完数据后的固定动作：先跑数据导出脚本，再按顺序跑 HTML 补丁脚本（**`新增HTML_危险动物专区.py` 必须最后跑**，
它要最后包住 `loadMap`/`applyMap` 并在 `#modeSel` 上补「危险动物」一项），最后确认
`物资地图.html` 与 `index.html` 的 SHA256 一致。
