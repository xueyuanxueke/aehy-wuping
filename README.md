# 挨饿荒野 · 物资地图

游戏《挨饿荒野》各地图物资摆放位置的可视化网页：缩放/拖拽查看地图，按物资筛选并显示摆放圆点，支持搜索、最多 5 种物资同时叠加显示。

顶栏两个 Tab：

| Tab | 内容 |
|---|---|
| **物资位置** | 各图物资摆放点（圆点），支持搜索、自定义颜色/大小、最多 5 种叠加 |
| **猎物区域** | 各图**猎物活动区矩形框**（哪些坐标范围内能刷出/抓到该猎物），可多选高亮 |

## 在线访问 / 本地运行

| 方式 | 说明 |
|---|---|
| GitHub Pages | 仓库开启 Pages 后访问 `https://xueyuanxueke.github.io/aehy-wuping/` |
| 本地服务器 | 在本目录运行 `python -m http.server 8777`，访问 `http://127.0.0.1:8777/`（推荐，所有功能完整） |
| 双击打开 | 地图/图标/背景全部正常；外部 CSV 映射与 `data/物资位置.json` 受浏览器 file:// 限制无法加载，会自动回退 HTML 内置的旧数据（顶栏会显示「映射:内置」「数据:内置」） |

## 页面功能

**地图操作**：滚轮/双指缩放、拖动平移，顶栏切换 15 张地图；缩放时圆点大小自适应（放大不糊、缩小不断）。

**物资位置 Tab**

- 左侧列表按摆放数量排序，点击叠加到地图（最多 5 种），搜索框按名称/英文名/编号过滤；
- 顶栏「按物品聚合」：把同一物品的地面/树上/雪地/水面等多个模型合并成一条，点一次高亮全部变体点位；
- 左下角图例每行可改圆点颜色与大小，`↺ 恢复默认样式`，设置按浏览器本地保存。

**猎物区域 Tab**：按猎物多选高亮其活动区矩形框，悬停显示坐标范围。

**其它**：物资没有图标时显示名称首字徽标（彩色方块）；「背景图」开关控制羊皮纸底衬。

## 文件结构

```
物资一览/
├── index.html            # 入口页（与 物资地图.html 内容一致）
├── 物资地图.html          # 主页面（地图渲染 + 两个 Tab 的全部逻辑）
├── data/                 # 页面运行时 fetch 的数据（仓库只发布这 4 个）
│   ├── 物资位置.json       # 各图物资摆放点（15 图 / 19254 点）
│   ├── 物资映射.csv        # 编号 → 名称 / 英文名 / 预制体 / 图标（252 条）
│   ├── 物件变体.csv        # 物件 → 预制体 / 变体 / 所属物品（620 条）
│   └── 地图矩形.json       # 各图官方坐标矩形（Constants.sceneDituWHMap）
├── 地图图片/              # 15 张地图底图 + 羊皮纸底衬 dituBack.png
└── wupingIcon/            # 物资图标（页面优先从这里加载，缺失则回退 assets）
```

`data/` 下只有上面 4 个文件是页面实际加载的；存档数据库、名称全量表、猎物区域源数据、
