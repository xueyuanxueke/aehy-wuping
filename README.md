# 挨饿荒野 · 物资地图

游戏《挨饿荒野》各地图物资摆放位置的可视化网页：缩放/拖拽查看地图，按物资筛选并显示摆放圆点，支持搜索、最多 5 种物资同时叠加显示。

顶栏两个 Tab：

| Tab | 内容 |
|---|---|
| **物资位置** | 各图物资摆放点（圆点），支持搜索、自定义颜色/大小、最多 5 种叠加 |
| **猎物区域** | 各图**猎物活动区矩形框**（哪些坐标范围内能刷出/抓到该猎物），可多选高亮 |

## 物资映射.csv

每行一个物资编号：

```
编号,名称,英文名,预制体,图标
13,竹子,ZhuziTree,Prefab/Tree/ZuziTree,zhuziCailiao.png
```

- 映射是全局的：同一编号在所有地图中共用一条映射；各地图的数量由摆放记录自动统计。
- `图标` 只写文件名，页面按 `wupingIcon/<图标>` 加载；`wupingIcon` 中不存在时自动回退 `../assets/Texture2D/`，两级都没有则显示 `?`。
- 改完 CSV 刷新页面即可生效（无需改 HTML）。
- **`名称` 留空的行**：新版本补进来的条目先只填 `编号` + `英文名`，中文等确认后再手填。列表标题按 `名称 → 英文名 → #编号` 三级回退，所以留空也能认出是哪一条（图标仍是 `?`）。
- 需要批量补齐新版本条目时跑 `python pythonTool/补充新物资条目.py`（见下），它会自动把「存档里出现过但 CSV 没有」的编号，以及新版本新增的枚举（≥460）追加进来。

## 物资位置数据源（data/物资位置.json）

页面打开时会 `fetch("data/物资位置.json")`，成功则用它**覆盖** HTML 里内联的旧数据：每张图的 `rows`（物资点）、`prm`（世界矩形）、`tw/th`（底图尺寸）、`bg`（底图路径），并补齐存档里才有的新地图。加载失败（`file://` 直接双击、或文件缺失）就继续用内联数据，顶栏会提示「数据:内置」。

```json
{
  "meta": { "rowFields": ["id", "x", "z", "s", "tag"], "placeFields": "level/name/prm/tw/th/bg/prmSource/count/rows" },
  "places": [
    { "level": 1, "name": "泰国丛林", "prm": [500,194,-188.7,82.5,52.2,-88.6],
      "tw": 692, "th": 269, "bg": "地图图片/图1_泰国丛林.png",
      "prmSource": "official", "count": 990,
      "rows": [[1099, 12.85, -2.86, 0, "tag_0"]] }
  ]
}
```

- `rows` 的每项按 `[id, x, z, s, tag]` 排列：`id` 物资编号（同 `物资映射.csv` 的 `编号`）、`x/z` 世界坐标、`s` 状态（0 未拾取 / 1 已拾取）、`tag` 存档内唯一标记。
- `prm` 是 `[w, h, l, r, t, b]`：`l/r` = 世界 x 范围、`b/t` = 世界 z 范围（`w/h` 在换算中会被约掉）。网页换算式：`px = (x-l)/(r-l)*tw`，`py = (t-z)/(t-b)*th`。
- `prmSource` 为 `estimated` 的条目（图 10 荒野一家、图 12 幽冥之地、图 15 纳米比亚）是估算值：存档里没有官方世界矩形，只能由数据反推。图 10/12 用「物资点包围盒 × 1.12 / × 1.16、中心对齐」；图 15 底图已到位，改用「物资点 ∪ 猎物区域」并集、按 14 张 official 图统计出的数据占宽 0.918 / 占高 0.910 反推（因为珍珠鸡那类粗框会超出物资点范围）。拿到准确范围后直接改 JSON 里的 `prm` 并把 `prmSource` 改成 `official` 即可，**不用动 HTML**。
- `bg` 为空串表示没有底图，页面会画一张网格当坐标系（15 张图现在都有底图，这条只是以后新增地图时的兜底）。
- 存档里的 level 与网页「图 N」一一对应；level 10、12 在存档里还没有任何物资点，`rows` 为空数组。

**更新流程**：把新存档放到 `data/marooned_with_ed.db`（或改脚本里的路径），然后

```bash
python pythonTool/导出物资位置.py
```

脚本把三张表 `marooned_wuping_data`（level 1–9）、`_data2`（10–13）、`_data3`（14、15）按 level 取出，写成上面的 JSON。改完刷新页面即可，无需重跑任何改 HTML 的脚本。地图名称/`prm`/底图尺寸等元信息在脚本顶部的 `PLACES` 表里维护，新增地图在里面加一行。

## 图例自定义颜色 / 大小

选中物资后，左下角图例每一行自带两个控件：

- **圆形色块**：点击弹出取色器，修改该物资在地图上的圆点颜色（同时同步左侧列表圆点与图例）；
- **数字框**：修改圆点大小（3–20 px，默认 5）；
- 设置了自定义样式后，图例底部出现 **↺ 恢复默认样式**。

自定义按物资编号保存在浏览器 `localStorage`（键 `aehyCustom`），刷新和下次打开都保留；仅对当前浏览器有效，换设备/清缓存后回到默认配色。不修改任何数据文件。

## 地图背景

顶栏 **背景图：开/关** 按钮控制是否在地图下方显示羊皮纸底衬（`地图图片/dituBack.png`），状态记忆在 `localStorage`。

## 猎物区域 Tab

数据来自游戏程序集里的 `BasePlace.ListAnimalZone()`，字段与语义：

```json
{
  "animals": { "44": { "en": "TuziObj", "zh": "兔子", "icon": "tuziObj.png", "nameSrc": "official" } },
  "places": [
    { "place": 1, "name": "Place1",
      "bounds": { "minX": -200, "minZ": -70, "maxX": 90, "maxZ": 70 },
      "animals": [ { "key": 44, "boxes": [ { "minX": -168, "minZ": 25, "maxX": -40, "maxZ": 70 } ] } ] }
  ]
}
```

- 一个猎物可以有多块互不相连的栖息地，`boxes` 里每一块都是一个矩形；
- 判定是**开区间**：`minX < x < maxX && minZ < z < maxZ`（只看平面坐标，忽略高度）；
- `place` 编号与网页「图 N」一一对应（Place1 = 图1 泰国丛林，以此类推），目前覆盖 Place1–Place15（图 15 纳米比亚）。
- 图 10 荒野一家、图 12 幽冥之地、图 15 纳米比亚三张背景图都已到位，框直接画在底图上；这三张图的 `prm` 是估算值（见上一节），如与底图有偏移请按实际范围校准 `data/物资位置.json`。
- `nameSrc`：`official` 表示中文名取自 `物资映射.csv` 的 `Prefab/Animals/*Home` 记录，`inferred` 表示按英文枚举名推断；

交互与「物资位置」页一致：缩放/拖拽/悬停看坐标；左侧点猎物可高亮其活动区（可多选，选中后其余变暗）；`全选` 显示全部。

`物资地图.html` 里的 `ZDATA` 常量就是 `猎物区域.json` 的内嵌副本 —— **改数据后必须重跑 `pythonTool/新增HTML_猎物区域页.py`**，否则页面不会更新。

数据的推导过程、验证方法与可复用脚本见 `文档/逆向_陷阱与猎物区域/`（换游戏版本时按那里的手册重跑一遍即可）。

## 维护脚本（pythonTool/）

| 脚本 | 作用 |
|---|---|
| `同步图标.py` | 把 物资映射.csv 引用的全部图标从 `assets/Sprite`（优先）、`assets/Texture2D` 复制进 `wupingIcon/`；可重复运行 |
| `导出物资映射.py` | 从 HTML 内置映射重新导出 CSV |
| `导出地图图片.py` | 提取 HTML 中 base64 地图为外部 PNG；可重复运行 |
| `改造外部csv.py` | 给 HTML 加"外部 CSV 映射加载（带回退）"能力 |
| `修改HTML_图标与背景.py` | 图标两级回退 + 背景图开关 |
| `修改HTML_自定义颜色大小.py` | 图例自定义颜色/大小 |
| `新增HTML_猎物区域页.py` | 注入「猎物区域」Tab（样式 + DOM + JS 模块，数据取自 `data/猎物区域.json`） |
| `导出物资位置.py` | 从 `data/marooned_with_ed.db` 导出 `data/物资位置.json`；地图名称/`prm`/底图在脚本顶部 `PLACES` 表维护 |
| `新增HTML_物资数据外置.py` | 让网页启动时加载 `data/物资位置.json`（失败回退内置数据），并把 `CSV_URL` 指到 `data/` |
| `补充新物资条目.py` | 把「存档里出现过但 CSV 没有」的编号 + 新版本新增枚举（≥460）追加进 `物资映射.csv`，只填编号与英文名，中文留空；`--dry` 只看不写 |
| `新增HTML_未命名物资显示英文名.py` | 列表标题按 `名称 → 英文名 → #编号` 三级回退，让中文还没填的条目仍能认出来 |
| `物资地图_原版备份.html` | 原始数据备份 |

脚本均可重复运行（已应用的修改自动跳过），并会同时更新 `物资地图.html` 与 `index.html`。

> `新增HTML_猎物区域页.py` 会把整个 `猎物区域.json` 内嵌进 HTML，且 `新增HTML_物资数据外置.py` 依赖它注入的模块，所以**两个改 HTML 的脚本按上面的顺序跑**：先 `新增HTML_猎物区域页.py`，再 `新增HTML_物资数据外置.py`。日常改物资点数据只跑 `导出物资位置.py` 即可，不需要碰 HTML。

## 日常更新流程

**更新物资点数据**（游戏里又逛了一圈/新版本存档）：

1. 把新存档放到 `data/marooned_with_ed.db`（文件名不同就改脚本默认值或用 `--db`）；
2. `python pythonTool/导出物资位置.py` 重新生成 `data/物资位置.json`；
3. 浏览器刷新验证（顶栏应显示「数据:外置JSON 19254点」，点数随存档变化）；
4. `git add -A && git commit -m "说明" && git push`。

**更新物资图标/名称**：

1. 修改 `data/物资映射.csv`（新增/改名图标、更名物资等）；
2. `python pythonTool/同步图标.py` 补齐图标；
3. 浏览器刷新验证；
4. 提交。

**新版本新增物资/猎物**（游戏更新后，存档里出现了不认识的编号）：

1. `python pythonTool/补充新物资条目.py --dry` 先看一眼会补哪些（只读）；
2. 去掉 `--dry` 正式写入，`data/物资映射.csv` 会多出「只有编号 + 英文名」的行；
3. 刷新页面，左侧列表会以英文名显示这些条目，按需补 `名称`（中文）、`图标`；
4. `python pythonTool/同步图标.py` 补齐图标后提交。

**更新猎物区域数据**（游戏版本更新后）：

1. 按 `文档/逆向_陷阱与猎物区域/README.md` 的「新版本复用手册」重跑工具链（注意 `il2cpp_array_new` 的地址每个版本都会变，`tt2.py` 已改成自动探测，识别不到时用 `AEHY_ARRNEW=0x...` 强制指定），得到新的 `data/猎物区域.json`；
2. `python pythonTool/新增HTML_猎物区域页.py` 把它注入网页；
3. `python pythonTool/新增HTML_物资数据外置.py` 重新接上物资位置数据源；
4. 刷新验证后提交。

## 数据来源

地图与摆放坐标来自游戏存档数据库 `data/marooned_with_ed.db`；物资编号/预制体/图标来自游戏资源（`assets/Sprite` 与 `assets/Texture2D`）；猎物活动区由 `libil2cpp.so` 的 `BasePlace.ListAnimalZone()` 反汇编还原（方法见 `文档/逆向_陷阱与猎物区域/`）。仅供学习交流。
