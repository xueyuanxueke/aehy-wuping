# 挨饿荒野 · 物资地图

游戏《挨饿荒野》各地图物资摆放位置的可视化网页：缩放/拖拽查看地图，按物资筛选并显示摆放圆点，支持搜索、最多 5 种物资同时叠加显示。

## 在线访问 / 本地运行

| 方式 | 说明 |
|---|---|
| GitHub Pages | 仓库开启 Pages 后访问 `https://xueyuanxueke.github.io/aehy-wuping/` |
| 本地服务器 | 在本目录运行 `python -m http.server 8777`，访问 `http://127.0.0.1:8777/`（推荐，所有功能完整） |
| 双击打开 | 地图/图标/背景全部正常；仅外部 CSV 映射受浏览器 file:// 限制，会自动回退内置映射（顶栏有提示） |

## 文件结构

```
物资一览/
├── index.html          # 入口页（与 物资地图.html 内容一致）
├── 物资地图.html        # 主页面
├── 物资映射.csv         # 外部映射表：编号 → 名称/英文名/预制体/图标
├── 地图图片/            # 12 张地图背景 + 羊皮纸底衬 dituBack.png
├── wupingIcon/          # 物资图标（页面优先加载此处）
└── pythonTool/          # 维护脚本（不参与展示，不入库）
```

## 物资映射.csv

每行一个物资编号：

```
编号,名称,英文名,预制体,图标
13,竹子,ZhuziTree,Prefab/Tree/ZuziTree,zhuziCailiao.png
```

- 映射是全局的：同一编号在所有地图中共用一条映射；各地图的数量由摆放记录自动统计。
- `图标` 只写文件名，页面按 `wupingIcon/<图标>` 加载；`wupingIcon` 中不存在时自动回退 `../assets/Texture2D/`，两级都没有则显示 `?`。
- 改完 CSV 刷新页面即可生效（无需改 HTML）。

## 图例自定义颜色 / 大小

选中物资后，左下角图例每一行自带两个控件：

- **圆形色块**：点击弹出取色器，修改该物资在地图上的圆点颜色（同时同步左侧列表圆点与图例）；
- **数字框**：修改圆点大小（3–20 px，默认 5）；
- 设置了自定义样式后，图例底部出现 **↺ 恢复默认样式**。

自定义按物资编号保存在浏览器 `localStorage`（键 `aehyCustom`），刷新和下次打开都保留；仅对当前浏览器有效，换设备/清缓存后回到默认配色。不修改任何数据文件。

## 地图背景

顶栏 **背景图：开/关** 按钮控制是否在地图下方显示羊皮纸底衬（`地图图片/dituBack.png`），状态记忆在 `localStorage`。

## 维护脚本（pythonTool/）

| 脚本 | 作用 |
|---|---|
| `同步图标.py` | 把 物资映射.csv 引用的全部图标从 `assets/Sprite`（优先）、`assets/Texture2D` 复制进 `wupingIcon/`；可重复运行 |
| `导出物资映射.py` | 从 HTML 内置映射重新导出 CSV |
| `导出地图图片.py` | 提取 HTML 中 base64 地图为外部 PNG；可重复运行 |
| `改造外部csv.py` | 给 HTML 加"外部 CSV 映射加载（带回退）"能力 |
| `修改HTML_图标与背景.py` | 图标两级回退 + 背景图开关 |
| `修改HTML_自定义颜色大小.py` | 图例自定义颜色/大小 |
| `物资地图_原版备份.html` | 原始数据备份 |

脚本均可重复运行（已应用的修改自动跳过），并会同时更新 `物资地图.html` 与 `index.html`。

## 日常更新流程

1. 修改 `物资映射.csv`（新增/改名图标、更名物资等）；
2. `python pythonTool/同步图标.py` 补齐图标；
3. 浏览器刷新验证；
4. `git add -A && git commit -m "说明" && git push`。

## 数据来源

地图与摆放坐标、物资编号/预制体提取自游戏数据；图标来自 `assets/Sprite` 与 `assets/Texture2D`。仅供学习交流。
